## 🌟 About Me

Welcome to my profile! I am Tanvi Khedekar, a dedicated software enthusiast currently pursuing my **Master of Computer Applications (MCA)** after graduating with a **Bachelor of Business Administration in Computer Applications (BBA-CA)**. 

My journey into technology is driven by a passion for building functional, user-centric software and understanding low-level computing principles. Having a strong foundation in business applications paired with deep technical training allows me to approach software development with both user experience and architectural design in mind.

## 💡 Technical Expertise & Knowledge

### 🚀 Full-Stack Web Development (MERN)
I specialize in building end-to-end web applications using the MERN stack (**MongoDB, Express.js, React.js, Node.js**). My knowledge covers:
* **Frontend:** Building responsive, modern UI layouts using React.js, modern CSS, HTML5, and JavaScript (ES6+), focusing on reusable component structures and clean state management.
* **Backend:** Designing RESTful APIs with Node.js and Express, implementing route security, JWT authentication, and managing server-side middleware.
* **Databases:** Working with MongoDB using Mongoose schemas for NoSQL data structures, alongside Relational Database Management Systems (RDBMS) and custom SQL querying.

### ⚡ Core Systems & Fundamentals
Beyond web stack frameworks, I prioritize strong core computer science fundamentals:
* **Programming Languages:** Proficient in **C** and **C++**, with hands-on application of Object-Oriented Programming (OOP) paradigms (inheritance, encapsulation, polymorphism).
* **Data Structures & Algorithms:** Practical understanding of arrays, linked lists, stacks, queues, and fundamental algorithms for efficient problem-solving.
* **Computer Science Foundations:** Knowledge of Database Management Systems (DBMS), Operating Systems concepts, and Software Engineering practices.
